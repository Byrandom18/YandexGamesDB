# Yandex Games Analytics

Локальное веб-приложение на ASP.NET Core 9 (Blazor Server). Собирает **публичный каталог** [Яндекс Игр](https://yandex.ru/games/) в SQLite и считает спрос по жанрам, тегам и карточке: медианы, индекс перспективы, язык названий.

Это не официальный продукт Яндекса и не консоль разработчика. DAU, ARPDAU и retention по чужим играм недоступны.

## Возможности

- Сбор списка игр, жанров, тегов и подробных карточек (GQ, отзывы, инапы, платформы, описание)
- Обзор, жанры, теги, факторы карточки, каталог игр, студии
- Вкладка **Для разработчика**: что делать, аудитория, чеклист витрины, прокси прибыли, слова в названиях
- Статистика по **медиане и перцентилям**, а не только по среднему (хиты не раздувают жанр)

## Требования

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- Windows / macOS / Linux

## Запуск

```bash
dotnet run --launch-profile http --urls http://localhost:5191
```

Откройте http://localhost:5191. База создаётся в `data/catalog.db`.

## Сбор данных

На странице **Сбор данных**:

| Режим | Что делает |
| --- | --- |
| Пробный | ~4 страницы каталога (~480 игр) и топ жанров |
| Полный | Весь каталог, затем подробные карточки |

Повторный полный сбор **не перекачивает** уже сохранённые подробные карточки — докачивает только игры без `Enriched`. Остановленный прогон можно продолжить тем же «Полный каталог».

Источники: HTML `__appState__` на страницах каталога и `POST /games/api/catalogue/v2/get_games` (format `long`). Соблюдайте разумную нагрузку на публичный сайт.
